Help and privacy

Getting started

  1. Choose Vocabulary > Import vocabulary batch to review and add Screenshot Pair Helper ZIPs (or approved-batch JSON files) without replacing existing entries.
  2. Choose Vocabulary > Add vocabulary entry for a word screenshot, typed word, typed answer, or answer screenshot.
  3. Choose Vocabulary > Crop from screenshot for manual selection from a larger textbook page. Drag across the image to select the content, then assign it to either side.
  4. Save the entry. Create at least two entries to use Memory Match and Multiple Choice.
  5. Choose File > Save collection JSON regularly. Opening a JSON file will replace the current in-memory collection.

Local files and copyright

No uploads or web services are used. Your local study collection may contain textbook images; keep those personal materials outside the public source-code repository unless you have distribution permission.

Compatibility

Designed with conservative JavaScript for Pale Moon and Basilisk (UXP/Goanna); verification on those actual browsers is still required. Local-file download behavior differs between browsers, so test Save and Open before entering a large number of entries.
