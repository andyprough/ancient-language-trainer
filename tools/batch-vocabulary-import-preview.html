1. Open an exported screenshot-pairs ZIP

Choose a ZIP exported by the Screenshot Pair Helper. This reads the images locally. Nothing is uploaded, and your existing Ancient Language Trainer collection is not modified.

2. Review pairs and enter shared metadata

Uncheck any pair you don't want. Images are displayed as the original crops, without OCR or edited spelling. This tool does not yet merge entries into the main trainer.

3. Save the approved batch

This exports a portable ALT-approved-batch-1 JSON file containing the selected original PNGs as data URIs, the textbook/chapter, and optional notes. It is an intermediate batch file, not yet the game's normal Save Collection JSON format. We'll connect it to the game's internal collection in the next integration step.

Reminder: Preserve your originals and existing study collection JSON. Do not put textbook screenshots or derived batch JSON in your public Git repository without distribution permission.
